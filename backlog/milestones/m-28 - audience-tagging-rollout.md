## Description

Per-insight audience tagging on JDAnalysis so downstream artifacts (recruiter card, cover letter, prep, debrief, LinkedIn, build) can mechanically filter to the slice their reader cares about. Foundation + recruiter card (Phase 6) shipped 2026-05-06; this milestone tracks the full rollout including Phase 5 LLM-asserted overrides, the remaining artifact generators, render-time filtering, type tightening, and a manual tag-override UI.
